# Website 4.9.1-S30-3-HF2

Kleiner, freigegebener Logbuch-UX-Hotfix auf Basis von Website 4.9.1-S30-3-HF1.

## Zweck
Abgeschlossene Logbücher verschiedener Wettbewerbe konnten im Archiv identische Bezeichnungen wie `1. Spieltag` tragen. HF2 nummeriert die archivierten OSC-Tippspieltage global und ergänzt den Wettbewerb.

Beispiel:
- `1. Tippspieltag · Smugglerauftrag`
- `2. Tippspieltag · Smugglerauftrag`
- `3. Tippspieltag · Bundesliga`

Die fachliche Überschrift innerhalb eines geöffneten Logbuchs bleibt unverändert, z. B. `Bundesliga 1. Spieltag`.

## Unverändert
Grid, Kachelgrößen, Navigation, Highscore-Berechnung, Logbuchdaten, OpenLigaDB sowie Automatiken für Bundesliga, DFB-Pokal, Champions League und Europa League.
