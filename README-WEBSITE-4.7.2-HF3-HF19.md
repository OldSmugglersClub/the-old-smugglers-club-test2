# Website 4.7.2-HF3-HF19 – Test

Zuerst ausschließlich im Testrepository einspielen.

## Prüfpunkte Desktop
1. Aktueller Gleichstand: Überschrift „Das Führungsdeck“, alle Rang-1-Tipper gleichwertig sichtbar.
2. Keine künstliche Platzierung 1/2/3 bei Gleichstand.
3. Ranglistentabelle und umgebende Highscore-Flächen passen farblich zum Führungsdeck.
4. Wettbewerb-/Ansichtsumschaltung und Suche funktionieren unverändert.

## Prüfpunkte Mobile
1. Führende zweispaltig, ohne horizontales Überlaufen.
2. Namen dürfen umbrechen, aber keine Karte darf aus dem Highscore-Bereich laufen.
3. Ranglistenkarten darunter bleiben unverändert bedienbar.

## Normalfall
Bei später eindeutigen Plätzen 1, 2 und 3 schaltet die bestehende Datenlogik automatisch auf das klassische Podium um.
